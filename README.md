Overview
Shayan Pharmacy is a fully functional, professional, web-based pharmacy management system designed to streamline the operations of a modern pharmacy. Built using HTML, CSS, JavaScript, and Firebase, this application allows pharmacy owners to manage medicines, orders, and prescriptions efficiently while providing customers with a smooth and interactive experience.
The application combines a modern, app-style dashboard with a responsive layout, enabling seamless access across desktops, tablets, and mobile devices. The interface is enhanced with animations, charts, and a dark mode toggle, giving it a polished, professional feel.
🌟 Key Features
User Authentication
Secure login system with Firebase Authentication.
Admin login for managing medicines and monitoring orders.
Separate access levels for regular users and admins.
Medicine Management
Admin can add, update, and delete medicines.
Medicines are stored in Firebase Firestore, providing a persistent and reliable database.
Search functionality for quick access to any medicine.
Cart & Order System
Users can add medicines to a cart and place orders.
Orders are permanently stored in Firebase for easy retrieval.
Invoice generation and WhatsApp integration to send order details directly to the pharmacy.
Dashboard
Modern dashboard displaying total medicines, total orders, and cart items.
Interactive chart representing orders and sales trends.
Real-time updates from the database.
Prescription Upload
Customers can upload prescriptions directly through the website for pharmacy verification.
Professional Design
Dark mode toggle for a modern interface.
Responsive layout optimized for mobile and desktop screens.
Smooth hover effects, animated cards, and stylish fonts for enhanced user experience.
🛠️ Technology Stack
Frontend: HTML5, CSS3, JavaScript (ES6)
Backend: Firebase Authentication, Firebase Firestore
Charts & Animations: Chart.js for sales visualization
Responsive Design: CSS Grid and media queries for cross-device compatibility
